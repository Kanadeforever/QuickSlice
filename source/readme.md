# QuickSlice 源码、使用与构建说明

这是基于 PySide6 / Pillow 的 Windows 10/11 轻量切图工具，支持独立线段、T 字形裁切、透明 PNG 和多图片队列。切割线与候选断点只是画布覆盖层，不写入原始图像。全部 PNG 直接从原图像素计算导出。

## 目录说明

压缩包解压后得到一个 `QuickSlice\` 文件夹，该文件夹内直接包含 `docs\`、`source\`、`release\` 和 `.build\` 四个目录，`source\` 不再套第二层项目目录：直接运行 `source\build.bat` 构建，或运行 `source\run.bat` 以源码方式启动。构建结果仍保存在 `release\QuickSlice\QuickSlice.exe`；这里的 `QuickSlice` 是 PyInstaller OneFolder 运行目录，不是重复的源码目录。

## 编译要求

- Windows x64、Python 3.11 x64；可使用 `py -3.11-64` 或 `python`。
- 依赖固定在 `requirements.txt`：PySide6 6.8.3、Pillow 11.2.1、PyInstaller 6.14.2。
- 双击 `build.bat`：自动创建发行根 `.build\venv`，尝试安装固定依赖，运行全部单元测试，再生成 `release\QuickSlice\QuickSlice.exe`。构建成功和失败均会 `pause`，需要按任意键关闭窗口。
- 发行模式是 PyInstaller **OneFolder**：必须完整保留 `release\QuickSlice\` 内 EXE 和依赖文件。图标已从 `assets\quickslice.ico` 自动嵌入 EXE，并用于程序窗口。
- 若需离线构建，可提前放入对应 Python/Windows 平台的完整 wheel 及其依赖到 `tools\wheels\`，脚本会优先执行 `--no-index` 本地安装；本发行源码 ZIP **未附带 wheel 或 Windows EXE**，首次构建可能需要可用的软件包镜像。

已安装依赖后，直接双击 `run.bat` 或在项目目录执行 `python src\main.py` 运行源码。

## 界面说明

顶部工具栏只保留两个高频缩放入口：“适应窗口”（Ctrl+0）与“实际像素 100%”（Ctrl+1）；打开图片、导出 PNG、自动保存开关、添加切割线等命令分别位于文件菜单、编辑菜单或右侧控制栏，不在工具栏重复占位置。

窗口右上角菜单栏最右端（系统关闭按钮下方）有独立的 `?` 帮助按钮。点击打开可以滚动的**完整使用说明**。内容直接读取 `source\assets\软件使用说明.md`，构建时随资源一起放进 EXE 的运行环境中；右侧不再常驻多行操作说明。右侧“切割线管理”首次打开时默认使用既有最大宽度 360 逻辑像素，保留用户手动拖动调整；三个线段操作按钮合并为一行。帮助弹窗默认加宽、关闭按钮汉化为“关闭”，菜单栏右侧的 `?` 始终留有边距。

## 图片和队列

可直接拖入一张或多张 PNG、JPEG、WebP、BMP、TIFF；也可以按 Ctrl+O 在文件选择器中多选。一次加入多张图片会显示左侧队列；单击切换，不会丢失本次会话中各图片的切割线和撤销记录。点击队列右上角的小图钉可切换自动隐藏：画布左上角仅留下 30×30 的展开按钮，不再占用全高窄栏；悬浮队列宽度紧凑、高度有上限，移开隐藏；再次点击倾斜图钉恢复固定。队列列表不再出现水平滚动条，长文件名可悬停查看。移除队列项不会删除磁盘文件。

切割线编辑和常用快捷键：

1. 滚轮围绕鼠标缩放；中键拖动、空格＋左键拖动、Ctrl＋左键拖动均可平移。
2. 图片空白处右键创建贯穿式垂直线，Shift＋右键创建水平线。左键拖动线条改变位置；拖动选中线两端的圆点改变长度。
3. 右键现有线段，选择“在此设置断点”；候选菱形靠近交叉点时自动精确吸附，否则按鼠标坐标放置。也可以先选线后点击右侧“设置断点”，默认定位于最接近中点的有效交叉点。
4. 拖动橙色菱形或修改右侧“断点坐标”微调，满意后按“执行分断”（或画布焦点下按 Enter）才真正分断。分断后两半仍相接；可删除一半，或调整端点形成 T 字。
5. Delete 删除选中线段；方向键每次移动 1 像素，Shift＋方向键每次 10 像素；Ctrl+Z 撤销、Ctrl+Y 重做。Ctrl+0 适应窗口、Ctrl+1 设为 100%。
6. 视图菜单可更改高对比描边、切割线颜色和线宽，白底图也能看清。

## 导出及文件规则

**自动保存＋下一张（默认关闭）**：只在菜单栏“文件”开启后，点击当前图片的“导出当前图片（PNG）”或按 Ctrl+E，直接保存到 `原图所在目录\原图名称\`，不用选择保存位置。成功保存后有下一张队列图片就切换到下一张；只有一张或已经到最后一张则保持当前图待机，不循环。用户取消覆盖、取消导出或发生导出错误时，不会跳图。开关退出时保存到 `config/settings.ini`（EXE 版则保存在程序所在文件夹）。队列侧栏的“导出全部”按钮仍按原来的模式手动选择统一父目录，直接导出整个队列。

**手动模式（默认）**：点击“导出当前图片（PNG）”或按 Ctrl+E，只需选择**目标父文件夹**。程序会自动创建 `父目录\原图文件名\` 再保存 `原图文件名_R01_C01.png` 等，**不必手动新建原图同名文件夹**。队列中“导出全部”逐张处理，每张图各有单独子目录；批量同名冲突时采用 `_2` 等子目录后缀。同名已存在会在覆盖前确认，取消导出不删除已生成切块。若队列含未编辑图片，先询问是否包含整图导出；若选择“否”，再询问是否仅导出已有切割线的图片，二次拒绝才真正取消。本轮选择导出范围后才弹出父目录选择窗口。

**长文件名**：普通文件名无论是否超过十个字符都保持原名。只有按 Windows 文件名及完整路径限制预测确实过长时，才退回到原名前十个字符加八位哈希（不同名字不会轻易撞名），同时应用于输出子文件夹和切块文件名。对目标父目录已经过深的情况明确报错，不会强行覆盖其他文件；同目录下同主名的 PNG、JPG 等自动加格式后缀区分输出目录。

矩形区按整数坐标裁切；不规则区以最小外接矩形导出，区域外设透明；原图不被修改。JPEG 转 PNG 不能恢复 JPEG 原有有损信息，只保证不再次进行有损压缩。对无法确保高位深的格式，程序会拒绝导出而不是静默降精度。多帧图片暂不支持。

## 源码布局与验证

`src/main.py` 是主窗口与队列调度；`src/queue_panel.py` 是队列面板与悬浮/固定 UI；`src/canvas.py` 是高性能预览及切线/候选断点输入；`src/core.py` 是纯 Python 切割线模型、拓扑与无损导出；`src/tasks.py` 是后台解码及单张/多图导出。`tools/test_core.py`、`tools/test_segments.py`、`tools/test_split_workflow.py`、`tools/test_auto_save.py` 提供 26 项切图与导出测试；`tools/test_ui_layout.py` 用于无需 Qt 的界面入口静态检查；`tools/test_batch_scope.py` 模拟用户两次“是/否”，执行真实的批量导出范围判断函数。

**当前交付只有源码，未在当前环境安装 PySide6 或实际生成 Windows EXE。** 单元测试通过不等于 Windows GUI 已验证。全部重要架构、限制、测试和后续事项详见发行根目录的 `docs\完整接档.md`。
