# QuickSlice

**轻量、自由、无损的图片切割工具。**

QuickSlice 是一款基于 Python 和 PySide6 开发的 Windows 桌面图片切割工具，专注于提供快速、直观且精确的切图体验。

无需打开 Photoshop 等大型图像编辑软件，只需要拖入图片，添加和调整切割线，即可将图片拆分为多个独立的 PNG 文件。

软件支持传统网格切割，也支持 **独立线段编辑、自由分断及非矩形区域导出**，适用于漫画拆页、长图拆分、图片素材整理、UI 资源切割等场景。

## 功能特色

### 自由切割

- **自由添加切割线**：支持水平、垂直两个方向。
- **独立线段编辑**：切割线可以独立移动、延长、缩短和删除。
- **两步式分断**：先设置断点，调整位置后再执行分断。
- **交叉点优先吸附**：设置断点时优先识别已有切割线的交叉点。
- **精确坐标编辑**：支持直接输入像素坐标与线段端点。
- **区域自动识别**：根据实际切割线识别独立区域。
- **非矩形区域导出**：以透明 PNG 保存不规则切块。
- **撤销与重做**：支持回退和恢复编辑操作。

### 无损图片导出

所有切块均根据原始图片的像素坐标生成。

- 不使用预览缩略图作为导出来源。
- 不对切块进行缩放或重采样。
- 使用 PNG 无损压缩。
- 支持保留透明像素。
- 对非矩形区域使用透明背景。
- 输出每个独立切块，无须手动逐张保存。

**关于无损的说明：**

QuickSlice 所说的无损，指的是裁切过程中不对原始解码像素进行额外的有损压缩或缩放处理。

例如，将 JPEG 图片裁切后保存为 PNG，可以避免再次进行 JPEG 有损压缩，但无法恢复 JPEG 原本已经损失的图像信息。

对于当前处理流程无法保证原始像素精度的特殊格式，程序会进行保护性检查，而不是静默降低位深。

### 流畅的画布操作

QuickSlice 将画布交互与最终图片导出分离，尽量减少大尺寸图片对编辑响应速度的影响。

- 鼠标指针定位缩放。
- 画布自由平移。
- 快速适应窗口。
- 一键查看实际像素比例。
- 高对比度切割线。
- 支持自定义切割线颜色和粗细。
- 图片预览与原始像素坐标独立管理。

画布缩放和平移不会改变图片的实际尺寸，也不会影响导出的像素精度。

### 多图片队列

支持一次拖入或打开多张图片进行连续编辑。

- 多文件拖拽导入。
- 图片队列快速切换。
- 每张图片独立保存切割线及编辑状态。
- 显示待编辑、已编辑等状态。
- 批量导出队列图片。
- 可选择仅导出已经编辑的图片。
- 队列面板支持固定和自动隐藏。

不需要为了处理下一张图片反复关闭和重新打开程序。

### 自动保存与下一张

开启 **「自动保存＋下一张」** 后：

1. 编辑当前图片。
2. 点击导出。
3. 程序自动在原图所在目录创建输出文件夹。
4. 将切块导出为 PNG。
5. 保存成功后自动切换到队列中的下一张图片。

如果当前队列只有一张图片，或者已经处理到最后一张，则保存完成后保持当前状态，不再切换。

保存失败或取消导出时，不会自动跳过当前图片。

### 自动整理输出文件

QuickSlice 可以根据原图名称自动建立独立输出目录。

例如：

原始文件：

    漫画素材\
    ├─ P001.jpg
    ├─ P002.jpg
    └─ P003.jpg

自动保存后：

    漫画素材\
    ├─ P001.jpg
    ├─ P002.jpg
    ├─ P003.jpg
    ├─ P001\
    │  ├─ P001_R01_C01.png
    │  ├─ P001_R01_C02.png
    │  └─ ...
    ├─ P002\
    │  └─ ...
    └─ P003\
       └─ ...

普通导出模式可以自行选择目标父目录；程序会在该目录下为每张图片建立对应的子目录。

对于超长文件名，程序会根据 Windows 文件名及路径长度限制自动处理。只有确实超限时，才采用原文件名前 10 个字符配合短哈希的缩写形式，降低路径过长和文件名冲突的风险。

## 使用方法

### 1. 打开图片

可以直接将图片拖入软件窗口，也可以通过：

**文件 → 打开图片**

选择一张或多张图片。

支持以下输入格式：

| 格式 | 扩展名 |
|---|---|
| PNG | `.png` |
| JPEG | `.jpg`、`.jpeg` |
| WebP | `.webp` |
| BMP | `.bmp` |
| TIFF | `.tif`、`.tiff` |

### 2. 添加切割线

在图片上使用鼠标右键添加垂直切割线，使用 Shift＋鼠标右键添加水平切割线。

也可以通过右侧「切割线管理」面板添加切割线，并精确设置坐标。

添加后，使用鼠标左键拖动线段调整位置，或拖动线段端点调整切割范围。

### 3. 分断切割线

需要处理局部切割时，可以对已有线段进行分断。

1. 在目标切割线上右键设置候选断点。
2. 程序优先吸附到附近的切割线交叉点。
3. 拖动断点标记，或通过数值输入精确调整位置。
4. 确认位置后执行分断。

分断后的线段可以分别移动、伸缩和删除。

**注意：分断线段不等于立即切开图片。** 分断操作只是把原线段拆成可独立编辑的两段。最终切块仍由切割线形成的实际区域决定。

### 4. 导出图片

编辑完成后，点击「导出所有切割块（PNG）」。

软件会自动识别切割区域：

- 矩形区域：直接按矩形边界裁切。
- 非矩形区域：保留区域内部像素，区域外设置为透明。

导出的文件统一采用 PNG 格式。

对于多图队列，还可以使用「导出全部」进行批量处理。

如果队列中混有已编辑和未编辑图片，程序会询问是否导出全部图片，或仅导出已经编辑的部分。

## 鼠标与快捷键

| 操作 | 功能 |
|---|---|

## 安装与运行

### 系统要求

- Windows 10 / Windows 11
- Python 3（源码运行或自行构建时）
- PySide6
- Pillow
- PyInstaller（构建 EXE 时）

具体 Python 依赖以项目附带的 `requirements.txt` 为准。

### 使用已编译版本

如果下载的是预编译的 OneFolder 发行版，直接运行：

    QuickSlice.exe

即可启动程序。

OneFolder 包含程序及其运行所需的依赖文件，移动时应保留整个发行目录。

### 从源码构建

项目提供 Windows 一键构建脚本。

进入：

    source\

双击：

    build.bat

脚本会执行依赖准备、项目检查及 EXE 打包流程。

构建成功后，程序位于：

    release\QuickSlice\QuickSlice.exe

目前默认使用 **PyInstaller OneFolder** 模式。

选择 OneFolder 主要是为了减少单文件程序启动时的临时解包开销，同时方便依赖管理及问题排查。

首次构建可能需要网络下载相应依赖，后续能否离线构建取决于本地依赖缓存是否齐全。

## 设计原则

QuickSlice 不以替代 Photoshop、GIMP 等完整图像编辑器为目标。

它只专注于一件事：

**让图片切割尽可能快速、准确、自由。**

因此，项目遵循以下原则：

- **轻量化**：避免引入与切图无关的复杂编辑功能。
- **直接操作**：能够在画布上完成的操作，尽量不强迫用户使用多级菜单。
- **无损优先**：所有切块以原始图片像素为依据。
- **自由编辑**：不将切割方式限制为传统规则网格。
- **性能优先**：减少不必要的重复解码、重绘和计算。
- **批量友好**：尽量减少处理大量图片时的重复操作。
- **可维护性**：保留完整源码、构建脚本、测试及项目文档。

当前开发版本：**v0.4.0-test5**
