# QuickSlice 完整接档

## 一、项目目标、状态与验收

QuickSlice 是 Windows 10/11 平台的轻量 PySide6 无损切图软件，核心用途是拖入图片后，以横纵可编辑线段快速定义区域并无损导出 PNG。重要约束：画布必须跟手、按原图整数像素处理、预览与导出分离、绿色便携、不修改原图、无须启动 Photoshop。

- `v0.1.0-test1`：早期贯穿线网格版本。用户 Windows 实机确认“非常好用”；后提出纯白底线条难见和 T 字形切割需求。
- `v0.2.0-test1`：引入独立线段、端点伸缩、T 字形及非矩形区域透明导出、高对比描边、蓝色四格图标、Shift＋右键横线、Ctrl＋左键平移。旧式直接右键分断缺少断点预览与确认，用户实机反馈分断不好用。
- **`v0.3.0-test1`**：分断改为「定位候选断点→可调整→确认分断」；多图片队列、固定/自动隐藏侧栏、每张图独立线段与撤销栈、队列批量导出；所选目标目录下自动创建原图同名子目录；构建 BAT 在成功/失败时暂停。**本环境的非 GUI 自动测试共 19 项通过，但未安装 PySide6，未完成 Windows GUI 或 EXE 实机验证。**

- **`v0.4.0-test1`**：增加全局“自动保存＋下一张”开关；打开后 Ctrl+E/保存按钮不再询问父目录，直接将 PNG 输出到源图片所在目录的同名子目录。多图队列只在当前图片全部保存成功后切到下一张，单图或最后一张停留待机。关闭开关保留以前手动选择父目录的流程。新增 Windows 路径长度与单文件名保护：正常长度完整保留，超限才回退前十字符加八位稳定哈希。对同源目录不同图片格式的同名文件自动区分子目录；覆盖检测和导出共用统一命名函数。**累计 26 项非 GUI 测试通过，新版 Windows PySide6/EXE 仍待实机验证。**

**`v0.4.0-test2`（历史，目录整理）**：仅压平压缩包及单项目源码目录，去掉顶层版本文件夹和 `source\QuickSlice\`，源码文件直接位于 `source\`；构建与运行入口分别改为 `source\build.bat`、`source\run.bat`，脚本只向上一级定位项目根目录。切图算法、GUI 操作与 v0.4.0-test1 相同，保留 26 项核心测试、OneFolder 输出和自动保存功能。

**`v0.4.0-test3`（历史，界面优化与说明）**：根据用户截图和逐项审查结果，恢复 ZIP 顶层唯一 `QuickSlice\` 项目目录，内部直接为 `.build/docs/source/release`，无重复源码目录；顶部工具栏只保留“适应窗口”“实际像素 100%”；“打开、导出、添加线、自动保存”移除顶部重复快捷入口，文件与编辑菜单功能保留。队列标题右侧的固定切换改为 30×30 图钉图标、保留自动隐藏功能；右侧栏从首次显示起默认展开到现有最大 360 逻辑像素，不扩大上限，之后允许用户拖动；线段操作按钮合并至一行，列表末列自适应，切割统计不再重复显示图像尺寸；右侧删除常驻操作说明和自动保存复选框。菜单栏右上角新增 `?` 按钮，打开随发行资源提供的完整 `软件使用说明.md`，支持滚动阅读，帮助说明无需占用画布宽高。切割、分断、无损导出算法和原版快捷键保持不变。新增不依赖 PySide6 的界面代码结构验证；当前环境尚不能完成 Windows GUI 和 EXE 实机验收。

**`v0.4.0-test5`（当前，队列/帮助/批量导出修复）**：自动隐藏队列不再用占据窗口全高的 30 像素按钮作为布局成员，而在画布左上角显示 30×30 小按钮；展开时仅弹出约 248 像素宽、最多 640 像素高的队列面板，不改变主画布缩放；面板宽度上限收至 260 逻辑像素，列表文件名列自适应、状态列固定且禁用水平滚动，避免底部滚动条挤占空间。菜单栏右侧帮助按钮改为带 8 像素内边距的独立定位方式，规避 Qt cornerWidget 在部分 Windows DPI 布局被边缘裁切；帮助窗口默认宽度至约 1000 逻辑像素并适配显示器可用空间，关闭按钮固定为中文“关闭”。批量导出碰到无切割线图片时，先询问是否含未编辑原图整张导出；拒绝后再询问是否仅导出已编辑图片；只有再次拒绝才取消，且两次确认都在弹出目标目录选择器之前进行。新增无需 Qt 的真实范围判断测试，保留原有切割和导出核心。尚无 Windows GUI 实机验收，不声称已经通过。

当前 ZIP 的**内部顶层恰好有一个 `QuickSlice\` 目录**，其中包括完整源码、测试、构建脚本、图标与独立使用说明。历史用户验证结果只证明对应已测版本，不自动证明本次 UI 通过验收。

## 二、代码与数据流

```text
多文件拖拽 / Ctrl+O 多选 / 命令行多个路径
        │
        ▼
main.py：QueueDocument 队列、每图模型/撤销记录/状态切换
        ├── queue_panel.py：列表、固定/自动隐藏、导出队列
        ├── tasks.LoadTask：后台解码有上限的预览像素
        │       ▼
        ├── canvas.ImageCanvas：Qt 直接绘图、滚轮缩放、平移、线段编辑和断点标记
        │       ▼
        ├── core.SliceModel：Guide 独立线段、分断候选交叉点、区域连通分析
        │       ▼
        └── tasks.ExportTask / BatchExportTask：后台写盘、取消/进度
                ▼
            core.export_png_tiles：重新读取原图，按原像素裁切为 PNG
```

`src/core.py` 完全不依赖 Qt，可以独立测试切割几何、像素保真、队列顺序和 Windows 输出路径策略。`src/canvas.py` 只在当前可见视口绘制图片，图像预览可能有降采样；用户拖动时不执行拓扑 BFS。`src/main.py` 组织窗口、信号、快捷键、独立队列图档与导出确认。`src/queue_panel.py` 只负责 UI 和队列消息，不在 UI 主线程解码图片。`src/tasks.py` 将图片解码和压缩导出放入 `QThreadPool`；工作线程只通过信号回到主线程。

## 三、线段结构与区域拓扑

`Guide(identifier,axis,position,start,end)`：`axis=h` 是水平，`axis=v` 是垂直；`position` 是垂直于线的坐标；`start/end` 是沿线段的原图整数像素坐标。范围 `0 ≤ start < end ≤ 图片对应轴的长度`，线的固定坐标不能位于外边框。同轴同坐标不允许实际长度重叠，但允许端点相接。稳定 ID 用于 UI 编辑和撤销/恢复。

新增 `split_intersections(id)`：找出真实覆盖目标线段内部的垂直交叉线，返回排序后的合法内部坐标；目标线端点不能作为分断位置。新增 `split_candidate(id,鼠标坐标,容差)`：在换算自 11 个屏幕像素的范围内优先吸附最近交点，否则取鼠标坐标对应的原图整数坐标并夹在合法范围。数字框的精确输入不强制吸附。

**设置断点不修改模型**：主画布上的黄色菱形只是待确认候选标记；可用鼠标拖动，或在右侧输入精确坐标。点击“执行分断”、再次打开线段右键菜单确认，或者在画布焦点下按 Enter 才真正执行 `split(id,coord)` 并创建撤销点。分断后两段首尾仍相接，区域不自动产生缺口；删掉半段、调整端点或移动后才可能改变裁切结果。选中另一条线会清空候选标记，切换图片亦清空，避免误在错图操作。

`tiles()` 使用横纵位置与端点建立整数小格网格，线段相当于小格之间不允许跨越的隔墙。广度优先搜索把相互连通的小格归为同一区域，同一行与相邻行小格再合并成矩形片段。若区域是矩形，直接原像素 PNG 裁切；若区域不规则，以最小外接框裁切，区域以外的 Alpha 设为 0。网格上限 350000 小格，线段最多 5000 条。结果缓存在模型中，只有编辑操作使其失效；仅平移、缩放或放置候选断点不会重新分析拓扑。

典型 T 字：创建通高纵线后，将水平线延伸到纵线；可直接缩短水平端点，或在交叉点设置断点、确认分断、删除不需要的半段。正确结果为三个独立矩形。L 字不规则区域按透明外接框导出。

## 四、队列编辑及内存策略

一次多选或多文件拖拽将所有有效图片按顺序加入队列并显示左侧队列；单图片时不显示队列，不浪费画布空间。文件以绝对路径去重。队列单击切换图片，移除只删除列表记录、**绝不删除磁盘源图**。

每张队列图片各自有 `SliceModel`、当前选中线、撤销/重做栈、预览缩放和偏移。切换图片会保留已编辑内容，在需要时重新后台读取预览，UI 只保留当前图和少量 LRU 预览缓存，预算约 180 MiB（若单张预览自身超过预算，仍必须保留这一张）。批量导出时逐张读取完整源图，不把所有完整图片同时载入内存。含有未编辑图片时，先询问是否将它们按完整图片导出；若拒绝，再询问是否仅导出已编辑图片。二次拒绝才取消导出，确认范围后才选择保存父目录。

队列默认固定左侧。点击队列标题右上角的 30×30 小图钉可取消固定，仅保留画布左上角的 30×30 浮动按钮；鼠标移到按钮展开不超过 640 像素高的紧凑队列，离开后自动隐藏。倾斜图钉可恢复常显。浮动面板只在打开期间覆盖画布左上角的有限区域；面板离开后自动隐藏，不挤压画布，不重算缩放和位移。固定选择会保存在配置 `[queue] pinned`。自动保存模式保存在 `[export] auto_next`，不影响其它画布操作。

## 五、导出规则、安全与限制

**全局自动保存工作流**：仅通过菜单栏“文件→自动保存＋下一张（原图目录）”配置全局开关，初始关闭，退出时写入 `settings.ini` 中的 `[export] auto_next`。开启后当前图片点击“导出当前图片（PNG）”或按 `Ctrl+E`：不弹目标目录对话框；自动导出到 `源图所在目录\源图主名\`，比如 `D:\漫画\章节001.jpg` 写入 `D:\漫画\章节001\章节001_R01_C01.png`。当前图片导出全部成功时才按队列列表的下一项继续，队列末尾或单张停留当前图片，不循环、不自动继续保存下一张。关闭后仍需选择目标父目录。左侧“导出全部”按钮仍保持原来的手动选定父目录并一次导出全部的功能，避免在自动模式下混淆两种工作流。

自动模式下如果目标切块已存在，仍会预先提示并要求用户确认覆盖；点击否不保存也不跳图。取消、异常、输出不完整时停留原图；已经写完的切块保留。自动模式保存成功后只在状态栏提示，不弹出每张一遍的完成对话框，以免中断连续切图。

**名称与路径保护**：NTFS 单组件理论限额为 255 个 UTF-16 单元，但 Windows 传统路径限额通常为 260 个 UTF-16 单元，因此本工具采用保守的 240 单元完整路径预算和 240 单元单组件预算，避免把长路径开关视为强制前提。正常源图名超过十字符时依然使用完整原名。只有规划出的子目录或带 `_Rxx_Cxx.png` 后缀的文件会超限时，才使用 `原名头十字符_8位SHA256` 作为文件夹和切块名前缀，以避免不同长文件名共享前十字符导致覆盖。若父目录本身过深，即使简称仍不能安全输出，则明确报错，请用户移动源图至更浅路径或在手动模式下选择短目录，不会静默截断目标路径。

若同一个源文件夹同时存在 `scene.png` 和 `scene.jpg`，自动模式分别建立 `scene_png` 与 `scene_jpg` 子目录避免混写；批量手动导出同名图按 `_2` 等后缀区分。上述命名由 `core.export_subfolder` 和 `core.tile_output_path` 统一计算，主线程覆盖检查与工作线程真正保存使用完全一致的目标路径。

在“导出当前图片”时，只需选择**父目录**，自动创建 `父目录\原图文件名（去扩展名）\`。如 `漫画001.jpg` 选 `D:\切图`，切块导出到 `D:\切图\漫画001\漫画001_R01_C01.png` 等，不需要用户事先创建同名目录。批量导出也是每张图片一个独立子目录；不同路径但同名的图片，队列内第二张使用 `_2` 后缀，以免同一批次互相覆盖。原有切块已存在则导出前集中提示，经确认才使用 `os.replace` 覆盖；取消时已经完成的文件保留，当前临时 PNG 清理。

- 全部导出使用 Pillow 重读源图；不使用 Qt 降采样预览，坐标不取整缩放，不进行 JPEG 二次编码。
- JPEG→PNG 仅保证相对于 JPEG 解码后的像素不再有新增有损，无法恢复 JPEG 原来已经损失的信息。
- RGBA PNG 矩形裁切逐像素一致；非矩形区域内部 RGBA 一致，外部强制透明；16 位 RGB/RGBA PNG 在当前解码器无法保证原位深时拒绝；高位深单通道的非矩形透明导出也拒绝。
- EXIF 方向处理后，预览与导出坐标一致。ICC 和 DPI 尽可能保留，不承诺保留每一种原图元数据。多帧动画不支持；大图可能需要大量解码内存，不能宣称无限图片大小。
- 原始图片只读；菜单和队列移除操作均不会对原图进行任何修改。

## 六、当前操作与快捷键

| 操作 | 行为 |
|---|---|
| 多图片拖拽或 Ctrl+O 多选 | 全部加入队列；单击队列项切换 |
| 鼠标滚轮 | 以鼠标位置为支点放大缩小 |
| 中键拖动 / 空格＋左键 / Ctrl＋左键 | 平移画布，三种方式保留 |
| 图片空白区域右键 | 新增贯穿整图的垂直线 |
| Shift＋右键 | 新增贯穿整图的水平线 |
| 左键拖线 / 拖已选中线的圆点 | 移动整段 / 改起点或终点 |
| 右键已有线段→设置断点 | 候选位置优先吸附附近真实交叉点，不立即分断 |
| 拖动橙色菱形 / 右侧断点数字框 | 调整断点候选位置 |
| 执行分断 / 画布 Enter / 右键再确认 | 真正将线分为独立两段 |
| Delete | 删除选中线段 |
| 方向键 / Shift＋方向键 | 沿线段垂直方向移动 1 / 10 个原图像素 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做，按当前图片分别记录 |
| Ctrl+0 / Ctrl+1 | 适应窗口 / 显示 100% |
| Ctrl+E | 导出当前图片；自动模式下保存成功后切换下一张（若有） |
| 文件菜单“自动保存＋下一张” | 全局开关：保存到原图目录、成功后推进队列；默认关闭 |

顶部仅保留“适应窗口”“实际像素 100%”两个直接操作按钮，菜单栏保留全部对应命令和快捷键。菜单栏最右端预留 8 逻辑像素的 `?` 帮助按钮打开完整软件使用说明，使用 `assets/软件使用说明.md` 随发行资源一并打包；帮助窗口默认约 1000 像素宽，并自动遵守显示器可用空间，按钮显示中文“关闭”，说明不常驻右侧栏。右侧“切割线管理”默认采用原本最大宽度 360 逻辑像素，之后允许拖动调整；队列顶部固定开关改为小图钉，不再占用整行空间。工具栏重复的打开、导出、自动保存、加线入口已删除；右侧重复的自动保存开关和常驻操作说明也已删除。切块当前图的按钮与队列批量导出按钮分属不同作用域，继续保留。

切线默认青色＋黑色高对比轮廓，当前选中线黄色；橙色菱形专门表示尚未执行的断点候选。视图菜单可调整切线颜色、描边和粗细；所有覆盖标记仅影响预览，绝不写入裁切的 PNG。
